⚙️ Настройки API

📥 Импорт словаря из файла

Формат файла: Каждая строка: слово|определение

Пример:
кот|домашнее животное семейства кошачьих
собака|домашнее животное, друг человека

📤 Экспорт словаря в файл

Экспорт словаря: Скачайте все слова из словаря в текстовом формате для резервного копирования или использования в других системах.
